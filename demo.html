Enterprise Incident Postmortem Generator

Production-ready incident management system for SRE teams

Enterprise Features

User authentication with role-based access control, database storage, analytics dashboard, SLA tracking, multi-channel notifications, and comprehensive audit logging.

Core Capabilities

Web-based interface, JSON/YAML input support, Google SRE-style postmortems, contributing factors analysis, and action items management.

Integrations

Jira integration, Slack notifications, email alerts, webhook support, and Prometheus metrics export.

How to Run the Application

# Install dependencies
pip install -r requirements.txt

# Run the application
python run.py

Then visit: http://localhost:8000
